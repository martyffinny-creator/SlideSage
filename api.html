Overview

The SlideSage API gives you programmatic access to AI-powered presentation analysis. Upload any PowerPoint, Keynote, or PDF and receive structured feedback on design, content, narrative flow, and more—in under 30 seconds.

The API is RESTful, uses standard HTTP verbs, and returns JSON. All requests are authenticated with Bearer tokens.

ℹ️
Base URL: https://api.slidesage.io/v2 — All requests must be HTTPS.

Quick Start

Upload a presentation and get an AI analysis in three steps.

cURLCopy
# Step 1 — Analyze a presentation
curl -X POST https://api.slidesage.io/v2/analyze \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@presentation.pptx" \
  -F "mode=full"

# Response
{
  "id": "rpt_8fKx2mN4pQ",
  "status": "processing",
  "estimated_seconds": 18,
  "webhook_url": null
}
PythonCopy
import slidesage

client = slidesage.Client("YOUR_API_KEY")

# Analyze a file
report = client.analyze("pitch-deck.pptx", mode="full")
report.wait()  # poll until ready

print(report.overall_score)   # 87
print(report.summary)         # "Strong narrative arc..."
for issue in report.issues:
    print(issue.slide, issue.type, issue.description)

Authentication

All API requests require a Bearer token in the Authorization header. Obtain your API key from the dashboard.

HTTPCopy
Authorization: Bearer YOUR_API_KEY_HERE
⚠️
Never expose your API key client-side. Use environment variables or a secrets manager. Rotate keys immediately if compromised.

Endpoints

POST Analyze Presentation

POST/analyze

Upload a presentation file and start AI analysis. Returns a report ID for polling or webhook delivery.

ParameterTypeRequiredDescription
filefilerequiredPPTX, PPTM, KEY, or PDF — max 50 MB
modestringoptionalquick, full (default), or deep
languagestringoptionalISO 639-1 language code, e.g. en, fr, de
webhook_urlstringoptionalHTTPS URL for result delivery when processing completes

GET List Reports

GET/reports

Returns a paginated list of all reports for the authenticated account.

ParameterTypeRequiredDescription
pageintegeroptionalPage number (default: 1)
per_pageintegeroptionalResults per page, max 100 (default: 20)
statusstringoptionalFilter by pending, processing, complete, failed

Webhooks

Set a webhook_url on any analysis request, and SlideSage will POST the completed report to your endpoint the moment analysis finishes — no polling required.

Webhook PayloadCopy
{
  "event": "report.complete",
  "report_id": "rpt_8fKx2mN4pQ",
  "overall_score": 87,
  "issues_count": 14,
  "report_url": "https://api.slidesage.io/v2/reports/rpt_8fKx2mN4pQ",
  "timestamp": "2026-04-02T14:30:18Z"
}

Validate webhook authenticity with the X-SlideSage-Signature HMAC-SHA256 header.
